PB115

AUR report card · Rule reference

duplicate-source-assignment

A second plain source= replaces the first: makepkg only ever reads the last one, and so does every checksum. A reviewer reading from the top, though, sees the first — which is how storageexplorer-bin staged a decoy source=('optimizer') above the array that really built it. Write one array, and extend it with +=. Assignments in different branches of a top-level if or case are alternatives, not overwrites, and are not reported.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put this directive on the offending line or the line above it:

# pkglint: ignore=PB115

It covers only that line pair, in that file. Passing --ignore PB115 turns the rule off for a whole run instead.
