PB209

AUR report card · Rule reference

uv-poetry-unlocked

--unsafe-fix

uv and poetry re-resolve dependencies unless told the committed lockfile is authoritative: uv sync/uv run without --frozen or --locked may rewrite uv.lock, and poetry update/poetry add abandon poetry.lock outright. Pass --frozen, and prefer poetry install against the committed lock.

Auto-fix

Run pkglint --unsafe-fix to rewrite this in place — the rewrite is mechanical but changes what the build does, so read the result. Add --diff to see the change without writing it.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB209

It covers only that line pair, in that file. Passing --ignore PB209 turns the rule off for a whole run instead.
