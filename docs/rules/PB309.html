PB309

AUR report card · Rule reference

hidden-unicode

Bidirectional-override and invisible/zero-width characters can make the rendered source differ from what the shell executes (the "Trojan Source" class of attacks). A PKGBUILD is ASCII shell; these controls have no legitimate place in it. The same goes for the host of url= or a source: a label that mixes Latin with Cyrillic, Greek or Armenian look-alikes (gіthub.com with a Cyrillic і), fullwidth letters, or an invisible character is a homograph of a name the reader trusts, and is an error; a label written wholly in another script is reported for review. Non-ASCII text in a URL's path, pkgdesc or a comment is not judged.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put this directive on the offending line or the line above it:

# pkglint: ignore=PB309

It covers only that line pair, in that file. Passing --ignore PB309 turns the rule off for a whole run instead.
