PB505

AUR report card · Rule reference

pacman-in-scriptlet

A scriptlet runs inside the pacman transaction that is installing its package, with the database lock held, so a pacman -S, -U or -R from it cannot do what it says: it fails on the lock, or, run detached until the lock clears, installs or removes packages the user never saw in the transaction summary. Dependencies belong in depends=; read-only queries (pacman -Q) are fine.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put this directive on the offending line or the line above it:

# pkglint: ignore=PB505

It covers only that line pair, in that file. Passing --ignore PB505 turns the rule off for a whole run instead.
