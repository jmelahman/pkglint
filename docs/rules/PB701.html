PB701

AUR report card · Rule reference

invalid-pkgname

pkgname and pkgbase may only contain the characters makepkg allows ([A-Za-z0-9@._+-]), must be ASCII, and must not start with a hyphen or dot. makepkg refuses to build a package whose name breaks these rules.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB701

It covers only that line pair, in that file. Passing --ignore PB701 turns the rule off for a whole run instead.
