PB834

AUR report card · Rule reference

missing-license-file

license=() must be declared, and licenses that aren't distributed system-wide (custom, LicenseRef-*, and any SPDX identifier not shipped in /usr/share/licenses/spdx) must install their text under usr/share/licenses/$pkgname/. Without it the package distributes software whose license terms the user can't read.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB834

It covers only that line pair, in that file. Passing --ignore PB834 turns the rule off for a whole run instead.
