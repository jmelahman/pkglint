PB912

AUR report card · Rule reference

duplicated-optdepends

--fix

A package listed in both depends and optdepends is contradictory metadata: the hard dependency always wins, and the optdepends line falsely suggests the feature is optional. Keep exactly one of the two. The auto-fix deletes the optdepends entry, which is the half with nothing behind it.

Auto-fix

Run pkglint --fix to rewrite this in place. Add --diff to see the change without writing it.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB912

It covers only that line pair, in that file. Passing --ignore PB912 turns the rule off for a whole run instead.
