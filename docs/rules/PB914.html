PB914

AUR report card · Rule reference

go-no-pie

--unsafe-fix

The Arch Go packaging guidelines build with -buildmode=pie: without it the Go toolchain links a position-dependent executable that ASLR cannot relocate, which PB806 flags on the built package. Set it in GOFLAGS or on the go build command; a PKGBUILD that chooses another -buildmode explicitly is left alone.

Auto-fix

Run pkglint --unsafe-fix to rewrite this in place — the rewrite is mechanical but changes what the build does, so read the result. Add --diff to see the change without writing it.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB914

It covers only that line pair, in that file. Passing --ignore PB914 turns the rule off for a whole run instead.
