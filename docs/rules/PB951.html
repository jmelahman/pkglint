PB951

AUR report card · Rule reference

cmake-build-type-release

--unsafe-fix

-DCMAKE_BUILD_TYPE=Release appends -O3 -DNDEBUG after the flags makepkg exports, silently overriding Arch's chosen -O2 and fortify settings. The CMake package guidelines build with -DCMAKE_BUILD_TYPE=None so the distribution's CFLAGS are what actually compile the code. The auto-fix rewrites the value to None, leaving the rest of the argument — a -D prefix, a :STRING type, the quoting — as written.

Auto-fix

Run pkglint --unsafe-fix to rewrite this in place — the rewrite is mechanical but changes what the build does, so read the result. Add --diff to see the change without writing it.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB951

It covers only that line pair, in that file. Passing --ignore PB951 turns the rule off for a whole run instead.
