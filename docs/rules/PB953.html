AUR report card · Rule reference

meson-missing-prefix

--unsafe-fix

Meson's install prefix defaults to /usr/local, which Arch packages must not touch; the Meson package guidelines configure with --prefix=/usr, or use arch-meson, which passes the distribution defaults for you.

Auto-fix

Run pkglint --unsafe-fix to rewrite this in place — the rewrite is mechanical but changes what the build does, so read the result. Add --diff to see the change without writing it.

Example
Suppress

If a package trips this rule on purpose and you have reviewed it, put the directive on the offending line or the line above it:

# pkglint: ignore=PB953

It covers only that line pair, in that file. Passing --ignore PB953 turns the rule off for a whole run instead.
